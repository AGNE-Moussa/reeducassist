# Documentation de RééducAssist

Toute la conception du projet est écrite ici, directement dans le dépôt, à côté du code.

## Contenu prévu

- Conception (tickets RA-010 à RA-017) : besoins, user stories, modèle de données, architecture.
- Décisions d'architecture (ADR) : une décision par fichier, avec son contexte et ses conséquences.

## Règles

- Données synthétiques uniquement, jamais de vraie donnée de santé, y compris dans les exemples.
- Un document modifié passe par une Pull Request, comme le code.
